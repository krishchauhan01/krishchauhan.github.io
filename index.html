Project 01

Quantitative Trading Strategy Backtesting System

Historical Market Data Analysis & Systematic Strategy Evaluation

Python | Pandas | NumPy | yFinance | Plotly | Jupyter

Python-based backtesting framework for evaluating systematic trading strategies against historical market data, combining time-series processing, simulated execution, performance analysis and interactive visualization.

Developed a Python-based quantitative trading backtesting system for evaluating systematic, rule-based trading strategies against historical financial market data. The project focuses on transforming raw market data into structured time-series datasets, applying strategy logic to generate trading signals, simulating trades, and analysing the resulting performance.

Built the workflow around Python's data analysis ecosystem, using Pandas and NumPy for time-series processing and numerical computation, yFinance and historical datasets for market data acquisition, and Plotly for interactive visualization. The framework allows strategies to be evaluated over historical periods without requiring live market execution.

Project 02

Financial Markets & Orderbook Management System

Relational Database Architecture for Financial Market Operations

SQL | MySQL | Relational Database Design | DBMS

Designed a MySQL-based relational database for modelling financial market operations, including instruments, accounts, orders, order-book activity, trades, positions and portfolio data, with emphasis on relational integrity and structured SQL analysis.

Designed and developed a relational database system for modelling core entities and workflows within a financial market environment. The project focuses on structuring financial instruments, users, accounts, orders, order-book activity, trades, positions and portfolio information within a consistent relational architecture.

The system was designed around database integrity, entity relationships and structured SQL operations, providing a foundation for storing and querying market and trading information. The project applies core DBMS principles to a realistic financial-market domain rather than a conventional generic CRUD application.
